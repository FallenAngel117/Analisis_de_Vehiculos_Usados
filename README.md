# Proyect7.- Análisis de Vehículos Usados

Esta aplicación web interactiva permite a los usuarios explorar visualmente un conjunto de datos de anuncios de vehículos usados en EE.UU. Utilizando **Streamlit**, **Plotly Express** y **pandas**, los usuarios pueden generar:

- Histogramas para ver la distribución de kilometraje (odómetro).
- Diagramas de dispersión para visualizar la relación entre año del modelo y precio, diferenciados por tipo de vehículo.
- Seleccionar visualizaciones mediante botones o checkboxes.

## Cómo ejecutarla localmente

1. Clona el repositorio.
2. Crea un entorno virtual e instala los paquetes con `pip install -r requirements.txt`.
3. Ejecuta la app:
   ```bash
   streamlit run app.py
